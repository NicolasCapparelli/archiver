# Implementation map

Exclude from orientation: `node_modules/`, `target/`, `dist/`, `src-tauri/gen/`, `rust-*.log`, `continuity/design/reading-room/qa/` and `continuity/design/reading-room/*.zip|pdf`.

Root rules: [AGENTS.md](../../AGENTS.md) (after implementation keep `src/feature-catalog.tsx`, [implemented features](../developer/implemented-features.md), [status](../status.md) and the [roadmap](../planning/roadmap.md) aligned). **After a routine change, rebuild and relaunch with `npm run launch`** ([setup](../developer/setup.md#see-your-change-npm-run-launch)).

## Routes

Emoji route: `src/emoji-selector.tsx` (Ctrl+Shift+J/palette dialog in `main.tsx`), `src/emoji-search.ts` (offline meaning keywords, literal ranking and responsive grid navigation), generated `src/data/emoji.ts` with Unicode source/license and `tools/generate-emoji.mjs`. Verify `tools/emoji.test.ts` via `npm run test:ui`; `api.deliverEmoji` shares `copy_item`/`paste_item` in Rust `main.rs` (optional item ID for generated Unicode text). Native delivery depends on [paste delivery](#paste-delivery), styling on [UI design](#ui-design). No catalog-browsing storage writes.

Verification defaults: Rust `npm run check:rust` and `npm test`; frontend `npm run build` and `npm run test:ui`; see [setup](../developer/setup.md#verify-a-change).

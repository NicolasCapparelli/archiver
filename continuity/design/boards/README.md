No Continuity design board is established. The retained [Reading Room study](../reading-room/README.md) (offline HTML `index.html`, PDF, QA images, tokens, assets) is the accepted visual reference for the implemented language; it is a study with sample data, not a board, and runtime source owns exact screens. To create one later, ask: "Read continuity/design/initialize-board.md and initialize the design board using [reference]." The reusable [board initialization prompt](../initialize-board.md) stays installed. Creating a board does not authorize rewriting app screens or adopting Aurora/TokenSeed.

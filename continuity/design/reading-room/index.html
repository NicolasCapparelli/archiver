Explicit deletion

Delete from archive
Retain current confirmation and recovery behavior. Do not imply that clearing the library deletes records.

Motifs

Small catalog tabs, inset selection rules, and fine section dividers create an archival rhythm. Content feels organized without mimicking a physical filing cabinet.

Motion

100 ms color changes for hover and selection. Up to 140 ms opacity with 4 px vertical travel for the quick panel. Focus immediately. No staggered rows or repeating ambient animation.

Accessibility and density

Body text targets at least 4.5:1 contrast. Focus, control boundaries, and selected edges target at least 3:1. Use text plus icons for state. Keep scrollbars discoverable, focus visible, and reduced motion immediate.

At smaller sizes

Keep Librarian search and footer visible; scroll results locally. At 900 × 400, Archivist reduces decorative heading space and keeps reachable details/actions. At 125–200% scaling, essential actions cannot rely on hover.

Use actual content as the hero

Do not introduce fake accession numbers, people, room illustrations, or decorative shelf rows in working surfaces.

The theme changes expression. It preserves capture, storage, search, and retrieval contracts.09 / 10
IMPLEMENTATION HANDOFF DESIGN READY / MIGRATION PENDING

A migration an agent can execute

Start with the supplied implementation brief. Apply this study to the existing UI and verify both windows before expanding scope.

  1. Establish the theme contract

    Map tokens.css into src/style.css. Preserve theme preference and cover all hardcoded surfaces, syntax colors, focus states, and dialogs.

  2. Replace identity and copy

    Remove Orbit marks, ring artwork, and space copy in src/main.tsx. Adopt catalog mark, window signatures, and clear library/archive language.

  3. Restyle the two windows

    Preserve 480 × 720 quick geometry and current shortcuts. Make Archivist results and details the visual priority.

  4. Carry the system through every tool

    Search, snippets, queues, timelines, OCR, diffs, settings, lifecycle, and command palette must use the same tokens.

  5. Validate and align documentation

    Frontend build and relevant UI checks. Rust checks only for Rust changes. Align feature catalog, STATUS, and ROADMAP with actual completion.

Nonnegotiable behavior

Preserve permanent archive history. Clearing the library changes visibility. Captures restore membership; command retries do not. Commands insert without execution.

Keep Ctrl+R shell search deferred. Experimental shell support and Windows-only OCR stay clearly labeled. New visuals do not imply new capabilities.

Release discipline

Generate icon assets for review, including monochrome tray output. Do not build or replace installers for this theme work.
